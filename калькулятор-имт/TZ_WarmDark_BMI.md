# Техническое задание (ТЗ) на редизайн HTML-калькулятора ИМТ в стиле «Warm Dark»

**Версия:** 1.0  
**Дата:** 01.10.2026  
**Объект:** одностраничное HTML/CSS/JS-приложение «Калькулятор индекса массы тела»  
**Цель:** перевести интерфейс из светлой нейтральной палитры в премиальную тёмную тему
(Warm Dark) с медными акцентами, добавить SVG-иллюстрирование и сохранить
полный функционал текущей версии.

---

## 1. Общая концепция

### 1.1 Дизайн-направление
**Warm Dark** — это тёмная тема, построенная не на «холодном» чёрном или
синем-графите, а на **тёплом угольном** основании с деликатными
**медными, янтарными и песочно-золотыми** акцентами. Ассоциативно — премиальный
wellness-продукт: минералы, кожа, дерево, медь, латунь, тёплый свет лампы.

### 1.2 Ключевые слова мудборда
`premium wellness` · `warm charcoal` · `copper accent` · `amber glow` ·
`tactile surface` · `editorial typography` · `quiet luxury` ·
`medical trust without clinical coldness`.

### 1.3 Ощущение от интерфейса
- Спокойный, дорогой, «вечерний» интерфейс.
- Тёплый световой контур у ключевых элементов (без неона).
- Мягкие, но читаемые границы; низкий уровень шума.
- Заголовки — с лёгким редакционным характером.
- Иллюстрации — тонкие SVG-контуры в медной гамме.

### 1.4 Аудитория и сценарии
- Взрослые 25–60 лет, интересующиеся здоровьем, весом, самочувствием.
- Использование вечером/ночью — тёмная тема снижает нагрузку на глаза.
- Пользователь открывает страницу, вводит возраст/рост/вес, получает ИМТ,
  категорию, норму веса, рекомендации и таблицу норм по возрасту.

### 2.2 Типографика

- **Стек шрифтов:** `"Inter", "Manrope", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
  (допускается без подключения внешних шрифтов — использовать системный стек).
- **Заголовок H1:** 1.7rem, вес 600, letter-spacing −0.01em.
- **Заголовок H2:** 1.15rem, вес 600.
- **Body:** 0.95rem, line-height 1.6.
- **Числовое значение ИМТ:** 2.6rem, вес 700, tabular-nums.
- **Подписи:** 0.78–0.85rem, цвет `--text-muted`.
- **Обязательно:** `font-feature-settings: "tnum" 1` для числовых блоков.

### 2.3 Пространство и радиусы

- Сетка: 4px. Основные шаги: 8 / 12 / 16 / 20 / 24 / 28 / 32.
- Радиусы: `--radius-sm: 8px`, `--radius: 14px`, `--radius-lg: 20px`.
- Контейнер: max-width 760px, центрирован.
- Padding карточек: 28px (20px на мобильных).

### 2.4 Тени и свечения

- Карточка: `0 1px 0 rgba(255,255,255,0.03) inset, 0 10px 30px rgba(0,0,0,0.45)`.
- Кнопка primary: `0 0 0 1px rgba(201,138,75,0.35), 0 6px 20px rgba(201,138,75,0.18)`.
- Фокус инпутов: `box-shadow: 0 0 0 3px var(--glow)`.
- Допускается лёгкий «шум» (SVG-фильтр или repeating-gradient) на фоне с непрозрачностью ≤ 3%.

### 2.5 Иконография и иллюстрирование (SVG внутри страницы)

Использовать **только inline SVG**, без внешних картинок и шрифтовых иконок.

Обязательные иллюстративные элементы:
1. **Шапка:** SVG-«силуэт человека в круге» — тонкий контур, штрих `--copper-dim`, толщина 1.25.
2. **Раздел ввода:** SVG-иконки у полей — календарь (возраст), линейка (рост), весы (вес), 18×18, stroke `--text-muted`.
3. **Шкала ИМТ:** сохранить, но перекрасить градиент в тёплую гамму категорий из 2.1.
4. **Фон:** одна мягкая SVG-«аура» (радиальный градиент меди на 3% непрозрачности) в правом верхнем углу.
5. **Декоративная сетка:** `background-image` с `linear-gradient` 1px линиями, цвет `rgba(201,138,75,0.05)`, шаг 32px, только в шапке страницы.

Правила SVG:
- `stroke-linecap="round"`, `stroke-linejoin="round"`.
- Никаких ярких заливок; только контур и мягкие полупрозрачные пятна.
- Все SVG — `aria-hidden="true"`, если они декоративные.

## 3. Структура страницы

Порядок блоков сохраняется как в текущей версии:

1. **Header**
   - H1 «Калькулятор индекса массы тела».
   - Subtitle «Рассчитайте свой ИМТ с учётом возраста и получите персональные рекомендации».
   - Декоративный SVG-силуэт справа (на мобильных — скрыт).
2. **Card «Ваши параметры»**
   - Сетка из трёх полей: Возраст / Рост / Вес.
   - У каждого поля: label, input, unit-подпись и SVG-иконка слева от label.
   - Кнопки: «Рассчитать ИМТ» (primary, медная), «Сбросить» (outline).
3. **Блок результатов (по умолчанию скрыт)**
   - Крупное значение ИМТ + категория (цвет категории).
   - Метрики: «Норма веса», «До нормы / Сбросить / В норме», «Возрастная группа».
   - Шкала ИМТ (SVG) с маркером и подписью значения.
   - Блок рекомендаций (тёплая подсветка слева, медная линия).
4. **Card «Справка: нормы ИМТ по возрасту»**
   - Пояснение формулы.
   - Таблица 7×7, горизонтальный скролл на мобильных, подсветка текущей возрастной колонки.
5. **Дисклеймер** — мелкий, приглушённый.

## 4. Компоненты

### 4.1 Кнопка Primary
- Фон: линейный градиент `--copper` → `--copper-hi` (мягкий, ≤ 12% разницы).
- Текст: `#1a1208`, вес 600.
- Радиус: 10px. Padding: 12px 20px.
- Hover: подъём на 1px + усиление тени.
- Active: `transform: translateY(0)`, тень слабее.
- Focus-visible: outline 2px `--amber`, offset 2px.

### 4.2 Кнопка Secondary
- Фон: прозрачный.
- Границы: 1px `--border`.
- Текст: `--text-muted`.
- Hover: границы `--copper-dim`, текст `--text`.

### 4.3 Input
- Фон: `--bg-elev-2`.
- Границы: 1px `--border`.
- Текст: `--text`, размер 1rem.
- Focus: границы `--copper`, свечение `--glow`.
- Убрать нативные стрелки number-input для единообразия (по желанию).

### 4.4 Metric-блок
- Фон: `--bg-elev-2`.
- Радиус 10px.
- Label: 0.78rem, `--text-muted`.
- Value: 1.15rem, вес 600, `--text`.

### 4.5 Recommendation
- Фон: `linear-gradient(135deg, rgba(201,138,75,0.10), rgba(224,178,106,0.04))`.
- Левая граница: 3px `--copper`.
- Радиус: 10px. Padding: 16px 18px.
- Заголовок — цвет `--amber`.

### 4.6 Таблица справки
- `thead th`: фон `--bg-elev-2`, цвет `--text-muted`, 0.78rem.

- Текущая колонка: фон `rgba(201,138,75,0.08)`, вес 600.
- Точки-индикаторы категорий — цвета из 2.1.

### 4.7 Шкала ИМТ (SVG)
- Полоса: линейный градиент из 7 тёплых стопов категорий.
- Границы значений (16 / 18.5 / 25 / 30 / 35 / 40+) — цвет `--text-dim`.
- Маркер: треугольник цвета `--text`, подпись значения — `--text`, вес 700.
- Подписи зон снизу — `--text-muted`, 0.72rem.

## 5. Поведение и взаимодействия

- Расчёт по кнопке и по Enter в любом поле.
- Валидация: возраст 14–120, рост 120–230, вес 30–300; при неверном значении — alert.
- После расчёта блок результатов плавно появляется и скроллится в видимую область.
- Маркер шкалы обновляется анимационно (`transition: transform .35s ease`).
- При «Сбросить» — возврат к значениям 30 / 175 / 70 и скрытие результатов.
- Тёмная тема применяется всегда (без переключателя).
- Обязательный `prefers-reduced-motion`: отключение анимаций и transition.

---

## 6. Доступность (a11y)

- Контраст текста к фону ≥ 4.5:1 для основного, ≥ 3:1 для крупного.
- Цвет категории **не единственный** носитель смысла — всегда есть текстовая подпись.
- У всех input — связанный `<label for>`.
- `aria-live="polite"` у контейнера результата, чтобы скринридер озвучил ИМТ после расчёта.
- Видимый `:focus-visible` для всех интерактивных элементов.
- Порядок табуляции — сверху вниз, слева направо.

---

## 7. Адаптивность

- Breakpoints: 600px (мобильный), 900px (планшет), >900px (десктоп).
- До 600px:
  - сетка полей — в одну колонку;
  - кнопки — во всю ширину, друг под другом;
  - H1 — 1.4rem, значение ИМТ — 2.1rem;
  - таблица — горизонтальный скролл, минимальная ширина 640px;
  - декоративная SVG-аура и шапка — уменьшены/скрыты.

---

## 8. Технические требования

- Один файл: HTML + встроенные CSS и JS. Без сборщиков и зависимостей.
- Без внешних шрифтов и изображений.
- Все SVG — inline.
- CSS-переменные в `:root`.
- Сохранить функции: `calculate()`, `updateMarker()`, `getRecommendation()`,
  `buildReferenceTable()`, `resetForm()` — и структуру данных `BMI_TABLE`, `AGE_GROUPS`.
- Семантическая разметка: `<header>`, `<main>`, `<section>`, `<table>`.
- Валидный HTML5, без ошибок в консоли.

---

## 9. Критерии приёмки

1. Фон тёмный, тёплый; акценты медные; неон и «кислотные» цвета отсутствуют.
2. Все тексты читаемы, контраст соответствует 6 разделу.
3. На странице есть минимум 4 SVG-иллюстрации (шапка, 3 иконки полей, шкала).
4. Расчёт ИМТ, категории, нормы веса, разницы, рекомендаций и таблицы — работают.
5. Шкала корректно позиционирует маркер при любом значении 16–40+.
6. Мобильный вид проверен на ширине 375px.
7. Скринридер корректно озвучивает результат.
8. Анимации уважают `prefers-reduced-motion`.
9. Страница открывается локально и работает без интернета.
10. Внешне выглядит как премиальный wellness-продукт, а не «тёмная тема ради тёмной темы».
