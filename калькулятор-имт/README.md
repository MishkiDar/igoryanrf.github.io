# Калькулятор ИМТ — Warm Dark

Редизайн HTML-калькулятора индекса массы тела в премиальной тёмной теме
**Warm Dark**: тёплый уголь + медные акценты + inline-SVG-иллюстрирование.

## Файлы

- **`TZ_WarmDark_BMI.md`** — полное техническое задание: дизайн-система
  (палитра, типографика, тени), структура страницы, компоненты, поведение,
  доступность, адаптивность, критерии приёмки и готовый промт для генерации.
- **`bmi_calculator_warm_dark.html`** — готовый одностраничный калькулятор
  по этому ТЗ. Открывается двойным кликом в любом современном браузере,
  работает офлайн, без внешних зависимостей.

## Как открыть

1. Скачайте `bmi_calculator_warm_dark.html`.
2. Откройте файл в браузере (Chrome / Firefox / Safari / Edge).
3. Введите возраст, рост, вес → «Рассчитать ИМТ».

## Что сохранено из исходной версии

- Расчёт ИМТ с учётом возрастной группы (6 групп).
- Определение категории по таблице `BMI_TABLE` (7 категорий).
- Диапазон нормы веса и разница с нормой («Добор / Сбросить / В норме»).
- Персональные рекомендации с возрастными примечаниями.
- SVG-шкала ИМТ с маркером текущего значения.
- Таблица норм по возрастам с подсветкой текущей колонки.
- Запуск по Enter, сброс к 30 / 175 / 70.

## Что добавлено

- Тёмная тема Warm Dark с медными акцентами и янтарным свечением.
- Медная «аура» и декоративная сетка в шапке.
- SVG-иллюстрации: силуэт человека, иконки полей (календарь, линейка, весы).
- `aria-live="polite"` для озвучивания результата скринридером.
- `:focus-visible` с медной обводкой.
- Поддержка `prefers-reduced-motion`.
- Плавная анимация маркера шкалы (0.35s).

## Технические характеристики

- Один файл: HTML + встроенные CSS и JS.
- Без сборщиков, шрифтов и изображений из сети.
- CSS-переменные в `:root`.
- Семантическая разметка, валидный HTML5.
